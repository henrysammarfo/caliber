- Why: largest multi-generator / multi-domain / adversarial benchmark; detector API returns `list[float]` scores (maps cleanly to miner `confidence` + binary AI/human); **MIT** on GitHub LICENSE + Hugging Face card.

- Secondary (smaller / cleaner essays): **Ghostbuster essay cleaned** https://huggingface.co/datasets/polsci/ghostbuster-essay-cleaned — **CC-BY-3.0** (attribution; commercial-friendly). Original Ghostbuster repo data: https://github.com/vivek3141/ghostbuster `data/`.

- **M4**: https://github.com/mbzuai-nlp/M4 — strong multi-generator corpus; **license for redistributing generations UNVERIFIED** in README (Tavily claimed LLM-dependent terms). Prefer RAID for H1.

## Exact label fields

### RAID (HF viewer / TinyFish fetch)
| Field | Role |
|---|---|
| `generation` | text to classify |
| `model` | generator id; value `human` = human-written; else LLM name (ChatGPT, GPT-4, …) → AI |
| `attack` | adversarial transform (`none` or attack name) |
| `domain` | genre/domain |
| `decoding`, `repetition_penalty` | sampling metadata |
| `id`, `source_id`, `adv_source_id` | ids |
| `title`, `prompt` | metadata |

Detector contract (RAID README): `def my_detector(texts: list[str]) -> list[float]` — per-text **AI probability / score** (float). Eval at target FPR (default 0.05).

Holdout recipe (recommended): stratified sample of RAID **test** split; keep `model==human` vs `model!=human` as binary ground truth; optionally include `attack!=none` for adversarial GRADELOCK cases. Do **not** train miner on same rows used as grader holdout.

### HC3
| Field | Role |
|---|---|
| `question` | prompt |
| `human_answers` | sequence of human replies |
| `chatgpt_answers` | sequence of ChatGPT replies |
| `source` | domain subset |
Binary labels derived by pairing answers (human vs ChatGPT), not a single probability column.

### Ghostbuster essay cleaned
| Field | Role |
|---|---|
| `text` | document |
| `label` | class label (**7 classes**, e.g. `0claude` and other generator/human tags — not a float probability) |
| `ID`, `filename`, `prompt` | metadata |

- Inputs standardized: `question`, `ground_truth`, `miner_answer` (not raw upstream JSON).
- Scores in `[0,1]`; empty/whitespace answer → exactly `0`; determinism across instances; no host imports; 32 MB size; ~128 KiB input cap mentioned.
- Register: `registerWasm(wasmHash, wasmUrl, intent)`; WASM hash **keccak256** (≠ miner YAML SHA-256).
- Stage 1 gates published; Stage 2 thresholds withheld.
